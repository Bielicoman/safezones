QUICK & EASY SETUP

Install in Less Than 60 Seconds

Compatible with Adobe Premiere Pro 2020, 2021, 2022, 2023, 2024, 2025 and CC 2026+.

01

Download & Unzip

Download the repository or release archive and extract the com.alexascencio.safezones folder.

Download ZIP from GitHub
02

Copy to CEP Folder

Press Win + R, paste the following path and hit Enter. Paste the com.alexascencio.safezones folder there:

%APPDATA%\Adobe\CEP\extensions\
03

Enable Unsigned CEP (1-Click)

Run this one-liner in Windows PowerShell (or Command Prompt) to allow developer CEP extensions:

reg add "HKEY_CURRENT_USER\Software\Adobe\CSXS.11" /v PlayerDebugMode /t REG_SZ /d "1" /f
04

Open in Premiere Pro

Start Adobe Premiere Pro and open your new panel from the top menu:

Window ➔ Extensions ➔ Safe Zones
01

Download Repository

Download and unzip the com.alexascencio.safezones directory.

Download ZIP for Mac
02

Copy to Mac CEP Folder

Open Finder, press Cmd + Shift + G and navigate to:

~/Library/Application Support/Adobe/CEP/extensions/
03

Enable PlayerDebugMode

Run this command in macOS Terminal to enable CEP extensions:

defaults write com.adobe.CSXS.11 PlayerDebugMode 1; defaults write com.adobe.CSXS.12 PlayerDebugMode 1
04

Launch Premiere Pro

Open Premiere Pro (native Apple Silicon M1/M2/M3/M4 & Intel compatible):

Window ➔ Extensions ➔ Safe Zones
