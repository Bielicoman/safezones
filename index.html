Como Usar o Safe Zones no Premiere

Sem complicações. Veja como elevar o nível das suas edições em 4 passos simples.

01

Ligue com 1 Clique (ON AIR)

Abra o painel em Janela > Extensões > Safe Zones. Clique no botão ON AIR. O plugin lê a resolução da sequência e cria uma faixa V4 travada.

Sequência: 1080×1920 ➔ V4 Travado 🔒
02

Escolha a Plataforma

Clique em TikTok, Reels ou Shorts. Os elementos de interface (botões de like, comentários e legenda) aparecem na hora.

Overlays Calibrados para 2025 ✓
03

Edite no Zone Studio Pro

Precisa de uma caixa para legenda, webcam ou enquadramento personalizado? Abra o Studio, use a Caneta Bézier (P) ou Formas e desenhe livremente.

Caneta com Curvatura Suave 🌊
04

Gerencie com o Botão Direito

Clique com o botão direito nos seus presets para Editar no Studio, Duplicar ou Exportar em .JSON para sua equipe.

ZONE STUDIO PRO VETORIAL

Um Estúdio Vetorial Dentro do Premiere

Sem precisar abrir o Photoshop ou Illustrator para desenhar uma margem de segurança ou moldura de facecam. O Zone Studio Pro roda nativo dentro do Premiere Pro.

  • Ferramenta Caneta (P): Crie nós vetoriais com curvatura suave Bézier (0% a 100% de suavidade).
  • Alinhamento Magnético Inteligente (🧲): Encaixe perfeito no centro, bordas e quartos de tela.
  • Pilha Completa de Camadas: Renomeie, reordene (▲/▼), oculte (👁️), tranque (🔒) ou exclua.
  • Ajuste Pixel a Pixel (Nudge): Use as setas do teclado para mover camadas com precisão cirúrgica.

Como Instalar no Seu Computador

Compatível com Adobe Premiere Pro 2020 a 2025+ no Windows e macOS.

01

Baixar Pacote do Plugin

Baixe o SafeZones.zxp para instalar com o ZXP Installer, ou baixe o SafeZones.zip com instalador automático em 1 clique (Instalar-Windows.bat).

Baixar .ZXP Baixar .ZIP
02

Copiar para a Pasta de Extensões

Pressione Win + R, cole o caminho abaixo e dê Enter. Cole a pasta com.alexascencio.safezones lá:

%APPDATA%\Adobe\CEP\extensions\
03

Liberar Extensões (Comando 1-Clique)

Abra o PowerShell ou Prompt de Comando e execute o comando abaixo para permitir extensões CEP de desenvolvedor:

reg add "HKEY_CURRENT_USER\Software\Adobe\CSXS.11" /v PlayerDebugMode /t REG_SZ /d "1" /f
04

Abrir no Premiere Pro

Abra o Premiere Pro e acesse o menu superior:

Janela ➔ Extensões ➔ Safe Zones
01

Baixar Pacote do Plugin

Baixe o SafeZones.zxp para o ZXP Installer, ou baixe o SafeZones.zip com script install-mac.command.

Baixar .ZXP Baixar .ZIP
02

Copiar para a Pasta CEP do Mac

No Finder, pressione Cmd + Shift + G e acesse:

~/Library/Application Support/Adobe/CEP/extensions/
03

Ativar PlayerDebugMode no Terminal

Execute no Terminal do macOS:

defaults write com.adobe.CSXS.11 PlayerDebugMode 1; defaults write com.adobe.CSXS.12 PlayerDebugMode 1
04

Abrir no Premiere Pro

Inicie o Premiere Pro (nativo Apple Silicon M1/M2/M3/M4 & Intel):

Window ➔ Extensions ➔ Safe Zones
📦

Instalador Oficial SafeZones.zxp

Baixe o arquivo SafeZones.zxp e arraste para dentro do Anastasiy’s Extension Manager ou ZXP Installer para instalação 100% automática no Windows ou macOS.
